# 🚀 AgentCraft Enterprise AI Report Generator

## Overview

The **Enterprise AI Report Generator** transforms raw workflow execution data into professional, executive-ready reports with interactive dashboards, PDF generation, charts, and multiple export formats.

This flagship feature positions AgentCraft as an enterprise-grade automation platform comparable to Salesforce, SAP, ServiceNow, Microsoft Power Platform, and UiPath.

## Backend Components

### 1. Report Generator Service (`backend/report_generator.py`)

Core service for generating report data:

```python
class ReportGeneratorService:
    async def generate_report(
        execution_id: int,
        workflow_id: int,
        workflow_name: str,
        workflow_nodes: List[Dict[str, Any]],
        execution_data: Dict[str, Any]
    ) -> Dict[str, Any]:
        """Generate complete report data structure"""
```

**Key Methods:**
- `_detect_workflow_type()` - Auto-detects workflow type from name and nodes
- `_generate_executive_summary()` - Calls AI to generate business-language summary
- `_extract_metrics()` - Extracts key metrics for dashboard
- `_extract_sections_data()` - Extracts data for report sections
- `_generate_audit_data()` - Creates audit trail information
- `_compute_fingerprint()` - Generates cryptographic hash for verification

### 2. Template Registry (`backend/report_templates.py`)

Manages report templates:

```python
class TemplateRegistry:
    @classmethod
    def get_template(cls, workflow_type: str) -> ReportTemplate
```

**Template Structure:**
```python
@dataclass
class ReportTemplate:
    id: str
    name: str
    workflow_types: List[str]
    sections: List[ReportSection]
    charts: List[ChartConfig]
    layout: str  # 'portrait' or 'landscape'
```

### 3. PDF Generator Service (`backend/pdf_generator.py`)

Generates enterprise-quality PDFs:

```python
class PDFGeneratorService:
    @staticmethod
    def generate_pdf(report_data: Dict[str, Any]) -> bytes:
        """Generate PDF from report data"""
```

**Features:**
- Professional typography and layout
- Headers and footers on every page
- Tables, cards, and sections
- Digital fingerprint in footer
- A4 compatible, print-ready

## Usage

### For Users

1. **Run a Workflow**
   - Create and execute any workflow in AgentCraft

2. **View Report**
   - When execution completes, click "View Enterprise Report" button
   - Report automatically generates with loading animation

3. **Export Report**
   - **Download PDF** - Professional PDF for printing or archiving
   - **Print** - Browser print dialog with optimized layout
   - **Markdown** - Export as markdown file
   - **JSON** - Developer mode - raw data export
   - **Copy** - Copy summary to clipboard

### For Developers

#### Generate Report Programmatically

```python
from backend.report_generator import ReportGeneratorService

# Generate report data
report_data = await ReportGeneratorService.generate_report(
    execution_id=123,
    workflow_id=456,
    workflow_name="My Workflow",
    workflow_nodes=nodes_list,
    execution_data=execution_dict
)

# Generate PDF
from backend.pdf_generator import PDFGeneratorService
pdf_bytes = PDFGeneratorService.generate_pdf(report_data)
```

#### Add Custom Template

```python
from backend.report_templates import TemplateRegistry, ReportTemplate, ReportSection

custom_template = ReportTemplate(
    id='custom',
    name='Custom Report',
    workflow_types=['custom', 'my_workflow'],
    sections=[
        ReportSection(title='Summary', type='text', data_key='summary'),
        ReportSection(title='Details', type='keyvalue', data_key='details'),
    ],
    layout='portrait'
)

TemplateRegistry.register(custom_template)
```

## Troubleshooting

### Report Not Generating

**Issue:** Report fails to generate  
**Solution:**
- Check execution completed successfully
- Verify workflow has valid data
- Check backend logs for errors
- Ensure GROQ_API_KEY is set

### PDF Download Fails

**Issue:** PDF generation errors  
**Solution:**
- Install reportlab: `pip install reportlab`
- Check backend logs for PDF errors
- Verify report data is valid
- Try with smaller dataset first

### Missing Executive Summary

**Issue:** AI summary not generated  
**Solution:**
- Verify GROQ_API_KEY is set and valid
- Check AI API quota/limits
- Review backend logs for AI errors
- Fallback summary will be used if AI fails
