# 🚀 AgentCraft v3.0 - Enterprise AI Report Generator

## Quick Start

### Installation (Windows)

```batch
# Run the installation script
install_reports.bat
```

Or manually:

```batch
# Install reportlab
pip install reportlab

# Verify installation
python -c "import reportlab; print('Installed:', reportlab.__version__)"
```

### Start Servers

```batch
# Terminal 1: Backend
python -m backend.main

# Terminal 2: Frontend
cd artifacts\agentcraft
npm run dev
```

### Test the Feature

1. Open `http://localhost:5173`
2. Go to "Workflows"
3. Select "Enterprise AI Procurement Orchestrator"
4. Click "Run Workflow"
5. Enter: "I need to purchase 10 Dell laptops"
6. When complete, click **"View Enterprise Report"**
7. See professional report with PDF download!

## What This Feature Does

Transforms raw workflow execution data into **professional, executive-ready reports** with:

- 📊 **Interactive Dashboard** - Beautiful metrics cards
- ✨ **AI Executive Summaries** - Professional business language
- 📄 **PDF Generation** - Enterprise-quality downloadable PDFs
- 📤 **Multiple Exports** - PDF, Print, Markdown, JSON
- 🔍 **Complete Audit Trail** - Digital fingerprints & traceability
- 🎬 **Animated UI** - Premium loading sequences & transitions
- 📱 **Responsive Design** - Works on all devices

## Key Features

### 1. Smart Workflow Detection

Automatically detects workflow type and generates appropriate report:

- **Procurement** → Purchase order report with budget analysis
- **Recruitment** → Candidate assessment with skills evaluation
- **Cybersecurity** → Incident investigation report
- **Email** → Delivery status report
- **GitHub** → Developer activity report
- **LeetCode** → Coding challenge report
- **Generic** → Fallback for any workflow

### 2. AI Executive Summary

Each report includes a professional executive summary generated by AI:

- Business Purpose
- Key Findings  
- Risk Assessment
- Recommendation
- Final Decision

### 3. Enterprise-Quality PDFs

Professional PDFs ready for archiving or distribution:

- Headers and footers on every page
- Professional typography and layout
- Digital fingerprint for verification
- A4 compatible, print-ready
- Tables, sections, and formatting

### 4. Multiple Export Options

- **Download PDF** - Professional PDF document
- **Print** - Browser print with optimized layout
- **Export Markdown** - Generate .md file
- **Copy JSON** - Raw data to clipboard

## API Endpoints

### Get Report Data

```
GET /api/executions/{execution_id}/report
```

Returns complete report data structure as JSON.

### Generate PDF

```
POST /api/executions/{execution_id}/generate-pdf
```

Generates and downloads PDF report.

## Usage Examples

### For Users

1. Run any workflow in AgentCraft
2. When execution completes, click "View Enterprise Report"
3. Download PDF, print, or export as markdown
4. Share with stakeholders or archive

### For Developers

```python
# Generate report programmatically
from backend.report_generator import ReportGeneratorService

report = await ReportGeneratorService.generate_report(
    execution_id=123,
    workflow_id=456,
    workflow_name="My Workflow",
    workflow_nodes=nodes,
    execution_data=data
)

# Generate PDF
from backend.pdf_generator import PDFGeneratorService
pdf_bytes = PDFGeneratorService.generate_pdf(report)
```

## Customization

### Add Custom Template

```python
from backend.report_templates import TemplateRegistry, ReportTemplate

custom_template = ReportTemplate(
    id='custom',
    name='Custom Report',
    workflow_types=['custom', 'my_type'],
    sections=[...],
    charts=[...]
)

TemplateRegistry.register(custom_template)
```

### Modify Existing Template

Edit `backend/report_templates.py` and modify the template definition.

## Troubleshooting

### reportlab Not Found

```batch
pip install reportlab
```

### Report Endpoint 404

Restart backend server after installing new code.

### AI Summary Shows Fallback

Set `GROQ_API_KEY` environment variable.

### PDF Generation Fails

Check backend logs for detailed error. Verify reportlab is installed.

### Common Questions

**Q: Do reports work with any workflow?**  
A: Yes! Reports are automatically generated for all workflow types. If no specific template matches, it uses the generic template.

**Q: Can I customize report templates?**  
A: Yes! Edit `backend/report_templates.py` or create new templates.

**Q: Are reports cached?**  
A: Currently generated on-demand. Caching is planned for future.

**Q: Can I email reports?**  
A: Not yet, but email delivery is planned for future release.

**Q: Do reports work offline?**  
A: PDF generation works offline. AI summaries require GROQ_API_KEY.
